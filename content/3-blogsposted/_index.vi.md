# Các bài viết đã đăng

Dưới đây là danh sách các bài viết kỹ thuật tôi đã xuất bản trên cộng đồng AWS Study Group trong quá trình thực tập:

---

## [Blog 1 - SPRING BOOT BACKEND DEPLOYMENT ON AWS ECS FARGATE WITH LOAD BALANCING](3.1-blog1/)

Bài viết này giới thiệu về việc triển khai một ứng dụng Spring Boot backend trên nền tảng AWS ECS Fargate, bao gồm cấu hình load balancer, database management, và CI/CD pipeline.

**Nội dung chính:**
- Kiến trúc cloud-native cho Spring Boot application
- Triển khai container trên Amazon ECS Fargate
- Cấu hình Application Load Balancer
- Quản lý database với Amazon RDS
- Thiết lập CI/CD pipeline với AWS CodeBuild

---

## [Blog 2 - CONTAINERIZING JAVA APPLICATIONS WITH DOCKER: BEST PRACTICES AND OPTIMIZATION](3.2-blog2/)

Bài viết này phân tích các best practices khi containerizing Java applications bằng Docker, từ tối ưu hóa Dockerfile đến triển khai trên Amazon ECS.

**Nội dung chính:**
- Docker fundamentals cho Java developers
- Tối ưu hóa kích thước Docker image
- Multi-stage Dockerfile build
- Security best practices cho containers
- Quản lý logging và monitoring

---

## [Blog 3 - INFRASTRUCTURE AS CODE WITH AWS CDK: AUTOMATING CLOUD DEPLOYMENTS](3.3-blog3/)

Bài viết này khám phá cách sử dụng AWS CDK (Cloud Development Kit) để tự động hóa triển khai hạ tầng AWS, giảm thiểu công sức thủ công và tăng tính tái sử dụng.

**Nội dung chính:**
- AWS CDK vs Terraform vs CloudFormation
- Viết IaC bằng TypeScript/Python
- Tự động hóa triển khai VPC, RDS, ECS
- Best practices cho CDK projects
- CI/CD integration với AWS CDK
